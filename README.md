MVP em HTML para controlar investimentos pessoais: registe o que comprou e quanto investiu, e veja a carteira organizada por activo e tipo.


# Meus investimentos

MVP para controlar investimentos pessoais. Sempre que investir, registe
o que é e quanto; a aplicação organiza tudo por activo e por tipo.

## Funcionalidades
- Registo de investimentos (data, activo, tipo, valor, quantidade)
- Total investido e peso de cada activo na carteira
- Distribuição por tipo de activo
- Ganho ou perda, com o valor actual indicado manualmente
- Histórico com editar e apagar
- Moedas: Kz (AOA), USD e EUR
- Exportar e importar cópia dos dados

## Como usar
Abra o `index.html` no navegador. Os dados ficam guardados localmente
no navegador (localStorage).
